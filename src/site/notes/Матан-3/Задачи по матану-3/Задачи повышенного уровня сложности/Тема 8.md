*Решения от Gemini задач повышенного уровня сложности из Темы 8 (Ряды Фурье)*

---

### Блок 1: Построение графиков и равномерная сходимость (5.1 – 5.6)

В этих задачах нужно определить свойства симметрии и периодичности функции по виду членов ряда, построить график и сделать вывод о сходимости.

**Общая теория для этих задач:**
1.  Если ряд содержит только **синусы**, функция нечетная: $f(-x) = -f(x)$.
2.  Если ряд содержит только **косинусы**, функция четная: $f(-x) = f(x)$.
3.  Аргумент **$2nx$** означает, что период функции $T = \pi$ (частота удвоена).
4.  Аргумент **$(2n+1)x$** означает антипериодичность с шагом $\pi$: $f(x+\pi) = -f(x)$.
5.  **Равномерная сходимость** ряда Фурье на всем периоде наблюдается, если периодическое продолжение функции **непрерывно** (нет разрывов на стыках и внутри периода) и функция кусочно-гладкая. Если есть разрывы — сходимость неравномерная (явление Гиббса).

---

**Условие 5.1:**
Пусть $f(x) = \sum_{n=1}^{\infty} b_n \sin 2nx$, $x \in (-\infty; +\infty)$, и $f(x) = x$ при $x \in (0; \pi/2]$. Нарисуйте график $f(x)$ на отрезке $[-\pi; \pi]$. Является ли ряд равномерно сходящимся на $[-\pi; \pi]$?

**Решение:**
1.  **Анализ свойств:**
    *   Ряд по синусам $\Rightarrow$ функция нечетная ($f(-x)=-f(x)$).
    *   Аргумент $2nx$ $\Rightarrow$ период функции $T = \pi$.
2.  **Построение графика:**
    *   На $(0; \pi/2]$ задано $y=x$.
    *   Так как функция нечетная, на $[-\pi/2; 0)$ график симметричен относительно начала координат: $y=x$.
    *   Итого на периоде $(-\pi/2; \pi/2]$ функция совпадает с прямой $y=x$.
    *   Далее график периодически повторяется с периодом $\pi$.
    *   В точках стыка $x = \pi/2 + \pi k$:
        $\lim_{x \to \pi/2-0} f(x) = \pi/2$,
        $\lim_{x \to \pi/2+0} f(x) = -\pi/2$.
3.  **Вывод о сходимости:**
    В точках $x = \pi/2 + \pi k$ функция имеет разрывы первого рода (скачки). Следовательно, ряд Фурье сходится **неравномерно** (в точках разрыва сумма ряда равна полусумме пределов, то есть 0).

**Ответ:** График — «пила» (прямые $y=x$ с разрывами в точках $\pm \pi/2, \dots$). Сходится неравномерно.

**Решения для однотипных задач (5.2 – 5.6):**

*   **5.2. Условие:** $f(x) = \sum b_n \sin(2n+1)x$, $f(x)=x$ на $(0; \pi/2]$.
    *   **График:** Функция нечетная. Аргумент $(2n+1)x$ дает симметрию относительно $x=\pi/2$ (вида $f(\pi-x)=f(x)$ для синусов нечетных гармоник). График на $(0, \pi)$ выглядит как треугольник: растет от 0 до $\pi/2$, затем падает к 0 в точке $\pi$.
    *   **Сходимость:** Функция непрерывна на всей оси (разрывов нет, $f(\pi)=0$). Сходится **равномерно**.

*   **5.3. Условие:** $f(x) = \sum b_n \cos 2nx$, $f(x)=x$ на $(0; \pi/2]$. (В условии опечатка $b_n$ вместо $a_n$, но суть ясна — ряд косинусов).
    *   **График:** Функция четная, период $\pi$. На $(-\pi/2, \pi/2)$ график $y=|x|$. В точках $\pm \pi/2$ значение $\pi/2$. Разрывов нет (стыкуются «галочки»).
    *   **Сходимость:** Непрерывная функция. Сходится **равномерно**.

*   **5.4. Условие:** $f(x) = \sum b_n \cos(2n+1)x$, $f(x)=x$ на $(0; \pi/2]$.
    *   **График:** Функция четная. Антипериодическая. На $(0, \pi/2)$ $y=x$. На $(\pi/2, \pi)$ график уходит вниз симметрично относительно точки $(\pi/2, 0)$, то есть $y = x - \pi$. В точке $\pi/2$ разрыв: слева $\pi/2$, справа $-\pi/2$.
    *   **Сходимость:** Есть разрывы. Сходится **неравномерно**.

*   **5.5. Условие:** $f(x) = \sum b_n \sin 2nx$, $f(x)=1$ на $(0; \pi/2]$.
    *   **График:** Нечетная, период $\pi$. На $(0, \pi/2)$ $y=1$, на $(-\pi/2, 0)$ $y=-1$. Классический «меандр» (прямоугольная волна). Разрывы в 0 и $\pi/2$.
    *   **Сходимость:** **Неравномерно**.

*   **5.6. Условие:** $f(x) = \sum b_n \cos(2n+1)x$, $f(x)=1$ на $(0; \pi/2]$.
    *   **График:** Четная. На $(-\pi/2, \pi/2)$ $y=1$. Из-за множителя $(2n+1)$ на $(\pi/2, 3\pi/2)$ будет $y=-1$. Разрывы в $\pm \pi/2$.
    *   **Сходимость:** **Неравномерно**.

### Блок 2: Экстремальные свойства коэффициентов Фурье (5.7 – 5.11)

Здесь используется свойство: частичная сумма ряда Фурье доставляет минимум среднеквадратичному отклонению среди всех тригонометрических многочленов того же порядка.

**Условие 5.9:**
Пусть $f(x)$ — кусочно-непрерывная на $[-\pi; \pi]$ нечетная функция, $a_k, b_k$ — коэффициенты её ряда Фурье. $C_k$ — произвольные числа. Чему равно наименьшее значение функции
$$ F(C_1, \dots, C_n) = \int_{-\pi}^{\pi} \left( f(x) - \sum_{k=1}^n C_k \sin kx \right)^2 dx? $$

**Решение:**
1.  Согласно экстремальному свойству ряда Фурье, интеграл (квадратичное отклонение) принимает наименьшее значение тогда и только тогда, когда коэффициенты многочлена совпадают с коэффициентами Фурье функции $f(x)$.
2.  То есть минимум достигается при $C_k = b_k$ (так как функция нечетная, разложение идет только по синусам).
3.  Подставим это в интеграл и раскроем квадрат, используя свойство ортогональности и равенство Парсеваля (для конечной суммы — тождество Бесселя):
    Min значение $= \int_{-\pi}^{\pi} f^2(x) dx - \pi \sum_{k=1}^n b_k^2$.

**Ответ:** $\int_{-\pi}^{\pi} f^2(x) dx - \pi \sum_{k=1}^n b_k^2$.

**Условие 5.10:**
Пусть $f(x)$ — кусочно-непрерывная на $[-\pi; \pi]$ **нечетная** функция. Чему равно наименьшее значение функции
$$ F(C_0, \dots, C_n) = \int_{-\pi}^{\pi} \left( f(x) - \frac{C_0}{2} - \sum_{k=1}^n C_k \cos kx \right)^2 dx? $$

**Решение:**
1.  Мы приближаем **нечетную** функцию суммой **четных** функций (константа и косинусы).
2.  Коэффициенты Фурье $a_k$ (при косинусах) для нечетной функции все равны 0.
3.  Следовательно, наилучшими коэффициентами $C_k$ будут нули: $C_0=0, C_k=0$.
4.  Сумма под квадратом зануляется, остается интеграл от квадрата самой функции.

**Ответ:** $\int_{-\pi}^{\pi} f^2(x) dx$.

### Блок 3: Дифференцирование рядов Фурье (5.15)

**Условие 5.15:**
Сколько раз можно почленно дифференцировать на отрезке $[-\pi; \pi]$ тригонометрический ряд Фурье функции:
*   $f(x) = (x^2 - \pi^2)^2$
*   $f(x) = \sin(\cos x)$
*   $f(x) = e^{\sin x}$

**Решение:**
Теорема гласит: чтобы ряд производных сходился равномерно (что позволяет дифференцировать почленно), исходная функция должна быть непрерывна, а ее периодическое продолжение должно быть гладким ("склеиваться" на концах периода).
Количество дифференцирований $k$ зависит от того, какая по счету производная $f^{(k)}(x)$ теряет непрерывность на концах периода (т.е. $f^{(k)}(-\pi) \neq f^{(k)}(\pi)$).

**1. $f(x) = (x^2 - \pi^2)^2$**
Проверим значения функции и производных на концах отрезка $[-\pi; \pi]$:
*   $f(\pm \pi) = (\pi^2 - \pi^2)^2 = 0$. (Совпадают $\Rightarrow$ $f(x)$ непрерывна).
*   $f'(x) = 2(x^2 - \pi^2) \cdot 2x = 4x(x^2 - \pi^2)$.
    $f'(\pm \pi) = 0$. (Совпадают $\Rightarrow$ ряд для $f'$ сходится равномерно).
*   $f''(x) = 4(x^2 - \pi^2) + 4x(2x) = 4x^2 - 4\pi^2 + 8x^2 = 12x^2 - 4\pi^2$.
    $f''(-\pi) = 12\pi^2 - 4\pi^2 = 8\pi^2$.
    $f''(\pi) = 8\pi^2$. (Совпадают $\Rightarrow$ ряд для $f''$ сходится равномерно).
*   $f'''(x) = 24x$.
    $f'''(-\pi) = -24\pi \neq f'''(\pi) = 24\pi$.
    Разрыв третьей производной. Ряд для $f'''$ не будет сходиться равномерно.

**Ответ:** 2 раза.

**2. $f(x) = \sin(\cos x)$ и $f(x) = e^{\sin x}$**
Обе функции являются сложными функциями, составленными из элементарных $2\pi$-периодических функций ($\sin x, \cos x$). Такие функции бесконечно дифференцируемы на всей числовой оси, и их периодические продолжения не имеют разрывов ни в самих функциях, ни в производных любого порядка.

**Ответ:** Бесконечное число раз.
