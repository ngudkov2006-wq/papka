***
### Формулировка теоремы

Пусть $z_0$ – конечная [[ТФКП/Определения ТФКП/Изолированная особая точка однозначного характера\|изолированная особая точка однозначного характера]] функции $f(z)$, чтобы она была [[ТФКП/Определения ТФКП/Устранимая особая точка\|устранимой особой точкой]], необходимо и достаточно, чтобы в проколотой окрестности точки $z_0$ разложение функции $f(z)$ в ряд Лорана имело нулевую главную часть.

---
### Доказательство

**1) Необходимость.**
Пусть $z_0$ [[ТФКП/Определения ТФКП/Устранимая особая точка\|устранимая особая точка]] функции $f(z)$, то есть существует конечный предел $\lim_{z \to z_0} f(z) = A$, из чего следует, что $f(z)$ ограничена в некотором кольце $0 < |z - z_0| < R$, то есть $\exists M > 0: |f(z)| \le M$.
Пусть $R_1: 0 < R_1 < R$, тогда модуль коэффициентов ряда Лорана функции $f(z)$:
$$ |c_n| = \frac{1}{2\pi} \int_{C_{R_1}} \frac{|f(\zeta)|}{|\zeta - z_0|^{n+1}} dl \le \frac{M}{R_1^n}, n = 0, \pm 1, \pm 2, \dots $$
$\frac{M}{R_1^n} \to 0, \text{ при } R_1 \to 0$, если $n < 0$, но $c_n$ не зависит от $R_1$, следовательно, $c_n = 0$, при $n < 0$, то есть главная часть ряда Лорана равна нулю.

**2) Достаточность.**
Пусть разложение в ряд Лорана в кольце $0 < |z - z_0| < R$ имеет вид:
$$ f(z) = \sum_{n=0}^{\infty} c_n(z - z_0)^n $$
Степенной ряд в правой части сходится в круге $|z - z_0| < R$ к голоморфной функции $S(z)$, причем $S(z) \equiv f(z)$ в кольце $0 < |z - z_0| < R$. В силу непрерывности $S(z)$ (сумма равномерно сходящегося ряда непрерывна при непрерывности функций функциональной последовательности составляющей ряд) получаем, что $\lim_{z \to z_0} f(z) = S(z_0) = c_0$, что по определению и означает, что точка $z_0$ – устранимая особая точка.
