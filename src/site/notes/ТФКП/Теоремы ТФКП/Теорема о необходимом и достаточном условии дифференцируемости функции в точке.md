### Формулировка теоремы

Для того, чтобы функция $f(z) = u(x, y) + iv(x, y)$ была дифференцируема в точке $(x_0, y_0),$ необходимо и достаточно, чтобы функции $u(x, y)$ и $v(x, y)$ были дифференцируемы в точке $(x_0, y_0)$, а их частные производные были связаны условием Коши-Римана:
$$ \begin{cases} u_x = v_y \\ u_y = -v_x \end{cases} $$

---
### Доказательство

#### 1) Необходимость.

Пусть $f(z)$ дифференцируема в $z_0$, тогда ее приращение, с одной стороны, имеет вид:
$$f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0) = \Delta f = \Delta u + i\Delta v$$
С другой же стороны по определению дифференцируемости функции:
$$\Delta f = \dot{f}(z_0)\Delta z + \alpha(\Delta z) = (A + iB)(\Delta x + i\Delta y) + \alpha_1(\Delta x + i\Delta y) + i\alpha_2(\Delta x + i\Delta y) =$$
$$= A\Delta x + iA\Delta y + iB\Delta x - B\Delta y + \alpha_1(\Delta x + i\Delta y) + i\alpha_2(\Delta x + i\Delta y)$$
где $A, B \in \mathbb{R}$.
Откуда сравнивая записанные выражения, получаем:
$$\Delta u = A\Delta x - B\Delta y + \alpha_1(\Delta x + i\Delta y)$$
$$\Delta v = A\Delta y + B\Delta x + \alpha_2(\Delta x + i\Delta y)$$
Введем обозначение:
$$\rho = |\Delta z| = \sqrt{\Delta x^2 + \Delta y^2}$$
Рассмотрим оценку (для $\alpha_2$ аналогична):
$$0 < \frac{|\alpha_1|}{|\Delta z|} = \frac{|\alpha_1|}{\rho} \le \frac{|\alpha|}{\rho}$$
По определению дифференцируемости:
$$\frac{\alpha(\Delta z)}{\Delta z} \to 0, \Delta z \to 0$$
Откуда следует, что:
$$\frac{|\alpha|}{\rho} \to +0, \rho \to +0$$
Тогда по ранее записанной оценке имеем, что:
$$\frac{|\alpha_1|}{\rho} \to +0, \rho \to +0$$
То есть по определению $o$ – малого:
$$\alpha_1 = o(\rho)$$
И так имеем:
$$\Delta u = A\Delta x - B\Delta y + o(\rho)$$
$$\Delta v = A\Delta y + B\Delta x + o(\rho)$$
То есть функции $u, v$ дифференцируемы в точке $(x_0, y_0)$, как функции многих переменных, причем:
$$u_x = A, u_y = -B$$
$$v_x = B, v_y = A$$
Таким образом приходим к условиям Коши-Римана:
$$ \begin{cases} u_x = v_y \\ u_y = -v_x \end{cases} $$

#### 2) Достаточность.

Пусть функции $u(x, y)$ и $v(x, y)$ дифференцируемы в точке $(x_0, y_0)$, тогда их приращения представимы в виде:
$$\Delta u = u_x\Delta x + u_y\Delta y + \alpha_1$$
$$\Delta v = v_x\Delta x + v_y\Delta y + \alpha_2$$
Введем обозначение:
$$\rho = |\Delta z| = \sqrt{\Delta x^2 + \Delta y^2}$$
Тогда $\alpha_1, \alpha_2 \to 0, \rho \to 0$.
Составим разностное отношение, где $\Delta z = \Delta x + i\Delta y$:
$$\frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z} = \frac{\Delta u + i\Delta v}{\Delta z} = \frac{u_x\Delta x + u_y\Delta y + \alpha_1 + i(v_x\Delta x + v_y\Delta y + \alpha_2)}{\Delta z}$$
Используем условия Коши-Римана:
$$\frac{\Delta f}{\Delta z} = \frac{u_x\Delta x - v_x\Delta y + \alpha_1 + i(v_x\Delta x + u_x\Delta y + \alpha_2)}{\Delta z} = \frac{u_x(\Delta x + i\Delta y) + iv_x(\Delta x + i\Delta y) + \alpha}{\Delta z} =$$
$$= u_x + iv_x + \frac{\alpha}{\Delta z}$$
Рассмотрим оценку:
$$0 < \frac{|\alpha|}{|\Delta z|} = \frac{|\alpha|}{\rho}$$
Воспользуемся неравенством треугольника:
$$\frac{|\alpha|}{\rho} \le \frac{|\alpha_1|}{\rho} + \frac{|\alpha_2|}{\rho}$$
По определению дифференцируемости функций $u(x, y)$ и $v(x, y)$
$$\frac{|\alpha_1|}{\rho}, \frac{|\alpha_2|}{\rho} \to +0, \rho \to +0$$
Тогда:
$$\frac{|\alpha|}{\rho} \to +0, \rho \to +0$$
То есть:
$$\frac{|\alpha|}{|\Delta z|} \to 0, \Delta z \to 0$$
Таким образом существует предел:
$$\lim_{\Delta z \to 0} \frac{\Delta f}{\Delta z} = u_x + iv_x = \dot{f}(z_0)$$
